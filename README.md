# Laramet

**Laramet** is a Laravel 12 starter kit fully integrated with the Metronic dashboard. It provides a solid foundation for building modern admin panels and web applications with clean architecture, ready-to-use UI components, and role-based access control.

## ✨ Features

- Laravel 12 with Blade templating
- Integrated Metronic UI (Metronic 8/9)
- User authentication (Laravel Breeze or Fortify)
- Role & permission management (Spatie)
- Responsive admin layout with reusable components
- DataTables, charts, alerts, modals, and form examples
- Modular SCSS, JS, and layout assets
- Ready for production deployment
